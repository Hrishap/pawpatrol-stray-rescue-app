# Illustrations

Drop the artwork here using these exact filenames — the app wires them up by
name, so anything not present simply falls back to the built-in vector icons.

| Filename            | Where it's used                                  |
| ------------------- | ------------------------------------------------ |
| `onboarding-1.png`  | Onboarding slide 1 hero ("Every stray deserves…") |
| `onboarding-2.png`  | Onboarding slide 2 hero ("Nearest rescuer…")      |
| `onboarding-3.png`  | Onboarding slide 3 hero ("Together, we map…")     |
| `role-reporter.png` | Role select — Reporter card                       |
| `role-volunteer.png`| Role select — Volunteer / Rescuer card            |
| `role-ngo.png`      | Role select — NGO / Shelter card                  |
| `species-dog.png`   | Fallback image for Dog cases + adopt cards        |
| `species-cat.png`   | Fallback image for Cat cases + adopt cards        |
| `species-cattle.png`| Fallback image for Cattle cases                   |

PNG or JPG both fine. Roughly square images work best for the role/species
slots; the onboarding heroes are shown in a ~280x200 rounded card.

Only use artwork you have the rights to ship — several of the reference images
gathered during design came from Pinterest and are likely under someone else's
copyright, so they're fine for private testing but need replacing (or licensing)
before this app is published.
